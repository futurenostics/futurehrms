## Findings

### Finding 1 — `font-tabular` → `tabular-nums`

- **Section:** "Foundation ready" card, permissions count `<span>`
- **Divergence:** Source used `font-tabular`. That's not a Tailwind
  default class — it's a leftover from an earlier custom-utility
  experiment that got pruned. The class resolves to no CSS in the
  current build (silently does nothing).
- **Resolution:** Swapped to `tabular-nums` (Tailwind's built-in
  font-variant-numeric utility, not on the ban list). Visual: the
  permissions count now uses tabular figures as originally intended.

### Finding 2 — `max-w-6xl` kept as-is

- **Section:** Outer container width
- **Divergence:** `max-w-6xl` is a Tailwind default size keyword
  (72rem / 1152px). Not on the numeric scale (doesn't end in a
  digit), so the lint rule doesn't ban it.
- **Resolution:** Kept as-is. The semantic fn-\* equivalent would be
  a layout-width token like `--fn-page-content-max`, but the
  catalog doesn't have one yet. The current 1152px is close to the
  design's ~1100-1200px content widths. Flagged for future
  catalog addition.
