## Why bundled

Per the Reset doc the canonical cadence is one commit per screen.
Bundling these four together because:

1. The toolkit applied is mechanically identical to the prior screen
   commits (Login, Dashboard, Employees list).
2. None of the four required hand-edits beyond a single
   `border-2 → border-[2px]` swap in the import dropzone (no
   border-width design token exists; arbitrary-px is the protocol-
   approved fallback).
3. None introduced new patterns or risk areas; the swap is a
   namespace rename that preserves every px value.
4. Separating into 4 commits would inflate the git log without
   adding bisect or revert value — all 4 succeed or fail together
   via the same lint/typecheck checks.

If any one of them later needs a per-screen revert or behavior
fix, the unrelated parts can be cherry-picked normally.

## Per-screen notes

### Profile page (`[id]/page.tsx`)

Largest of the four. Renders 7 distinct visual blocks: profile-
header card (composed component, separately remediated), inline
status / manager / salary action banners, tabs strip, Overview tab
with personal-info + employment-info + emergency-contact cards,
Timeline tab, Documents tab placeholder, and 3 modal dialogs for
status / manager / salary changes. Perl swap touched the page-
level classNames for every block; the composed sub-components
(ProfileHeader, change dialogs, dialog forms) are NOT remediated
in this commit — they're in separate skip-list entries.

### Import page (`import/page.tsx`)

Multi-step CSV wizard: upload → preview → review errors → commit.
Has a drag-and-drop dropzone, a preview table with row-level
status badges, an error-detail panel, and a commit-results screen.
The one non-mechanical fix (`border-2` → `border-[2px]`) is on
the dropzone — the design's dashed border is 2px and the only
place in the app that needs a non-1px border, so arbitrary-px
notation is the right call rather than adding a one-use token.

### Org chart (`org/page.tsx`)

Recursive node-tree renderer with collapsible branches. Smaller
classNames surface than the others; mostly the node-card paddings
and the connector-line offsets.

### App layout (`(app)/layout.tsx`)

Thin wrapper that mounts the AppShell + a query-client-error
fallback boundary. 11 violations from the fallback's empty-state
styling. The AppShell, Sidebar, Topbar components it mounts are
all still in the legacy skip-list (separate Tier 2 remediation
commits will land them).
