## Why bundled

Tier 2 + Tier 3 components share the same migration shape as the
screen files. Bundling 17 files because:

1. Toolkit is mechanically identical.
2. Each file individually is small (most have <20 violations).
3. The shell components compose into every screen — they're best
   migrated together so the visual surface stays internally
   consistent rather than having half-remediated chrome.
4. Per-file commits would inflate the git log by 17 entries for
   zero bisect or revert benefit.
